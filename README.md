# DuckbillTweak

한국 FFXIV용 Dalamud 편의 기능 모음. 필요한 트윅만 켜서 사용합니다.

**0.1.1.3 개발본: 기본 입찰 우클릭 메뉴에 '입찰 숫자 보기'를 추가하고 선택할 때만 화면을 열도록 수정했습니다. 빌드/리소스 검사와 재로드를 확인했습니다. 기본 메뉴 병행 동작과 상점 필터·스크롤의 인게임 재확인은 대기입니다.**

| 기능 | 사용 방식 |
|---|---|
| PvP 전장 말풍선 | 켜기/끄기만 제공. 채널·색·크기 등은 기본 대화 말풍선 설정을 따름 |
| 없는 품목만 보기 | 게임 상점 안의 체크박스. 등록한 수집품 또는 소지한 아이템 제외. 종류/현재 카테고리별 선택 기억 |
| 필요 재화 | 게임 상점 안의 버튼으로 열기. 기본은 미보유 품목, 종류·거래 여부 필터와 전체 보기 |
| 아이템별 입찰 숫자 | 게임 입찰 목록에서 아이템 우클릭 → 입찰 숫자 보기. 맨 위 아이템명, 8인 한 열/24인 세 열의 이름과 숫자 |

설정과 결과 화면도 게임 UI 컴포넌트/글꼴/현재 테마를 사용합니다. 이전 ImGui 보조 목록, 자동 팝업, 별도 채팅 오버레이, 말풍선의 독자 설정, 입찰 기록 비우기 버튼은 제거했습니다.

## 개발본 사용

공개 설치 패키지/커스텀 저장소 배포는 아직 없습니다. 빌드 후 Dalamud 개발 플러그인에 아래 DLL을 등록합니다.

```text
src/DuckbillTweak.Plugin/bin/Debug/DuckbillTweak.dll
```

같은 폴더의 Core DLL, **KamiToolKit.dll**, Assets와 라이선스 파일도 유지하십시오. DLL 하나만 옮기지 않습니다.

1. `/dbtw` 또는 `/duckbilltweak`로 게임 스타일 설정을 열고 필요한 기능을 켭니다.
2. 상점을 닫았다 열면 원래 화면 안에 `없는 것만 보기`와 `필요 재화`가 표시됩니다.
3. 일반 길 상점에서는 종류를 선택한 뒤 제외 체크를 바꿀 수 있습니다. 카테고리형 교환 상점에서는 기존 카테고리 선택을 사용하며 각 선택을 기억합니다.
4. 입찰 목록의 아이템 우클릭 메뉴에서 `입찰 숫자 보기`를 선택합니다. 미리보기 등 기존 메뉴는 유지합니다. `—`는 숫자 미수신이며 포기를 뜻하지 않습니다. 숫자는 입찰 결과 로그를 받은 뒤 표시합니다.

이전 기능 켜짐 상태는 유지하고 설정 형식은 v2로 전환합니다. 신규 설치에서는 기능이 모두 꺼져 있습니다. `/dbtw shop`, `/dbtw loot` 보조 화면 진입은 제거했습니다.

## 지원 범위

- 검사한 한국 게임 실행 파일 SHA-256과 FFXIVClientStructs 모듈 ID가 일치할 때만 네이티브 기능을 활성화합니다. 현재 대상은 KR 2026.10.06.0000.0000 / 설치된 KR Dalamud15.0.3.9입니다.
- Shop, InclusionShop, ShopExchangeItem의 확인한 ULD 구조를 대상으로 합니다. 목록/원본 인덱스 연결을 확인할 수 없으면 필터를 비활성화하고 원본 행을 유지합니다. 모든 특수/군표/부대 상점을 지원하는 것은 아닙니다.
- 상점 필터는 원본 데이터 배열을 재정렬하지 않습니다. 표시 행 클릭 시 원본 인덱스·아이템·컨텍스트를 재확인하며 구매 확정은 게임 UI에서 직접 진행합니다.
- 재화 합계는 NPC의 시트 품목 중 조건을 확인할 수 있는 교환식을 한 번씩 구매하는 기준입니다. 대체 경로의 기본 중복 선택을 방지하며 최저 비용 최적화는 아닙니다. 조건 미확인 교환식은 제외하고 그 수를 표시합니다. 길 합계는 기본 단가 기준이라 할인을 반영하지 않습니다.
- 보유 판단은 수집 등록 API와 일반 소지품·장비함·착용 장비입니다. 집사·초코보 가방·보관함은 포함하지 않습니다. 미확인 보유량과 소장가치별 수량을 0으로 추정하지 않습니다.
- 말풍선은 PvP(늑대우리 제외)에서만 검사한 네이티브 제한 처리를 조정하고, 해제/지역 이탈/언로드 시 원래 바이트를 복구합니다. 기본 말풍선이 꺼져 있거나 해당 채널이 꺼져 있으면 그대로 표시하지 않습니다. 전투/PvP 실기 확인은 남아 있습니다.
- 입찰 숫자는 로그로 수신한 것만 표시합니다. 같은 아이템 동시 드롭은 보상 슬롯 구분 불가로 안내합니다. 다른 연합 파티의 A/B/C 소속을 추측하지 않습니다. 캐릭터/지역 전환과 해제 시 기록을 비웁니다.

## 빌드

Windows/.NET SDK10.0.402, Dalamud.NET.Sdk15.0.0/API15를 유지합니다. 네이티브 UI에는 MIT 라이선스 KamiToolKit의 고정 소스 revision을 사용합니다.

```powershell
git submodule update --init --recursive
./scripts/build.ps1
```

다른 참조 위치는 `-DalamudPath '참조 폴더'`로 지정합니다. 스크립트는 잠금 파일 복원·빌드·내장 자료와 원본 JSON/필수 의존성 검사를 수행하며 자동 테스트나 게임 조작은 하지 않습니다.

```powershell
. ./scripts/enter-dev.ps1
dotnet run --project tools/GameDataProbe -- resources src/DuckbillTweak.Plugin/bin/Debug/DuckbillTweak.dll
dotnet run --project tools/GameDataProbe -- native-contract '게임 경로/ffxiv_dx11.exe' "$env:DALAMUD_HOME/FFXIVClientStructs.dll"
dotnet run --project tools/GameDataProbe -- '게임 경로/sqpack' audit
```
