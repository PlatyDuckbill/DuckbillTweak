# DuckbillTweak

한국 FFXIV용 Dalamud 편의 기능 모음. 필요한 트윅만 켜서 사용합니다.

**0.1.2.11 개발본: 화폐 교환 상점의 불필요한 아이콘 일치 조건을 제거했습니다. 코르보 서책의 실제 로그에서18개 교환 정보 복원과 수집 필터18→3행 적용을 확인했습니다. 상점 재열기/실제 탭 변경 때 체크를 해제하고, 필요 재화 버튼은 현재 체크를 이어받습니다.**

| 기능 | 사용 방식 |
|---|---|
| PvP 전장 말풍선 | 켜기/끄기만 제공. 채널·색·크기 등은 기본 대화 말풍선 설정을 따름 |
| 보유 수집품 제외 | 이미 보유·등록한 장비와 수집품만 제외. 마테리아·소모품·재료·하우징 유지. 상점/계산 창 체크 공유 |
| 수집 위주 보기 | 장비·등록 수집품·악보 중심. 확인된 소모품·재료·마테리아·하우징·지도·경주 용품 제외, 분류 미확인 유지 |
| 필요 재화 | 상점 버튼으로 열기. 현재 상점 목록의 필요량, 보유 수집품 제외·종류·거래 여부 필터와 전체 보기 |
| 아이템별 입찰 현황 | 원래 우클릭 메뉴 → 입찰 숫자 보기. 아이템 아이콘/이름, 참여자·선택 상태·주사위. 8인 한 열/24인 세 열 |

설정과 결과 화면도 게임 UI 컴포넌트/글꼴/현재 테마를 사용합니다. 이전 ImGui 보조 목록, 자동 팝업, 별도 채팅 오버레이, 말풍선의 독자 설정, 입찰 기록 비우기 버튼은 제거했습니다.

## 개발본 사용

공개 설치 패키지/커스텀 저장소 배포는 아직 없습니다. 빌드 후 Dalamud 개발 플러그인에 아래 DLL을 등록합니다.

```text
src/DuckbillTweak.Plugin/bin/Debug/DuckbillTweak.dll
```

같은 폴더의 Core DLL, **KamiToolKit.dll**, Assets와 라이선스 파일도 유지하십시오. DLL 하나만 옮기지 않습니다.

1. `/dbtw` 또는 `/duckbilltweak`로 게임 스타일 설정을 열고 필요한 기능을 켭니다.
2. 상점을 닫았다 열면 원래 화면 안에 `보유 수집품 제외`, `수집 위주 보기`, `필요 재화`가 표시됩니다.
3. 상점을 새로 열거나 실제 상점 탭/분류를 바꾸면 두 체크는 모두 꺼집니다. 체크 상태는 저장하지 않습니다. 필요 재화 버튼은 현재 체크를 이어받고, 어느 창에서 바꾸든 두 창에 함께 반영됩니다. 필요 재화의 종류·거래 필터는 새로 열 때 전체로 돌아갑니다.
4. `보유 수집품 제외`에 마우스를 올리면 적용 대상을 짧게 안내합니다. 보유 판정에는 설치된 Allagan Tools의 현재 캐릭터 보관 기록도 활용합니다. 어느 쪽에도 정보가 없으면 미확인으로 유지합니다. 낡은 악보는 제작 결과 악보가 모두 등록됐으면 제외합니다.
5. 입찰 목록의 아이템 우클릭 메뉴에서 `입찰 숫자 보기`를 선택합니다. 미리보기 등 기존 메뉴는 유지합니다. `—`는 숫자 미수신이며 포기를 뜻하지 않습니다. 숫자는 입찰이 끝나 결과 로그를 받은 뒤 표시합니다.

이전 기능 켜짐 상태는 유지하고 설정 형식은 v3로 전환합니다. 이전에 저장된 상점 체크 값은 사용하지 않습니다. 신규 설치에서는 기능이 모두 꺼져 있습니다. `/dbtw shop`, `/dbtw loot` 보조 화면 진입은 제거했습니다.

두 체크는 기준이 다릅니다. `보유 수집품 제외`는 보유/등록한 장비·수집품만 숨기고, `수집 위주 보기`는 보유 여부와 관계없이 확인된 소모품/재료 등을 숨깁니다. 둘을 함께 켜면 아직 없는 수집 대상 위주로 표시합니다. 예를 들어 집사 급료·암흑물질·마테리아는 보유 수량과 관계없이 첫 번째 체크만으로는 숨기지 않고, 두 번째 체크로 숨깁니다. Allagan Tools에 기록된 현재 캐릭터의 집사·초코보 가방도 보유 조회에 포함됩니다.

## 지원 범위

- 검사한 한국 게임 실행 파일 SHA-256과 FFXIVClientStructs 모듈 ID가 일치할 때만 네이티브 기능을 활성화합니다. 현재 대상은 KR 2026.10.06.0000.0000 / 설치된 KR Dalamud15.0.3.9입니다.
- Shop, InclusionShop, ShopExchangeItem, ShopExchangeCurrency의 확인한 ULD 구조를 대상으로 합니다. 목록/원본 인덱스 연결을 확인할 수 없으면 원본 행을 유지합니다. 필터 적용 실패 시에는 체크 해제를 허용하고 사유를 툴팁/로그에 남깁니다. 모든 특수/군표/부대 상점을 지원하는 것은 아닙니다.
- 상점 필터는 원본 데이터 배열을 재정렬하지 않습니다. 표시 행 클릭 시 원본 인덱스·아이템·컨텍스트를 재확인하며 구매 확정은 게임 UI에서 직접 진행합니다.
- 상점이 열려 있으면 현재 카테고리의 실제 수신 품목/수량/비용을 계산합니다. 대체 경로의 기본 중복 선택을 방지하며 최저 비용 최적화는 아닙니다. 구매 가능 여부 미확인 품목도 가격을 읽었으면 포함하며 그 수를 표시합니다. 수량을 읽지 못한 교환식은 제외합니다. 비용 미확인은 부분 합계로 안내하고 보유량 미확인을 0으로 바꾸지 않습니다. 다른 카테고리 전체를 자동 순회하지 않습니다.
- 화폐형/아이템 교환의 원본 가격이 비면, 페이지 전체의 품목 구성(중복 개수 포함)·받는 수량과 이미 읽은 비용을 게임 SpecialShop 자료에 대조합니다. 상점 이름도 일치하면 우선하며, 후보 교환식의 비용이 서로 다르면 복원하지 않습니다. 새로운 일반 아이템 재화는 Item ID로, 지갑 재화는 CurrencyManager의 실제 등록 여부와 수량으로 조회합니다. 특수 화폐 인덱스는 게임의 현재 매핑을 우선하고 검증한 자료를 보조로 사용합니다. 새로운 재화가 기존 지원 상점/게임 데이터 형식을 따르는 범위에서 개별 ID 추가 없이 계산합니다.
- 재화 창은 원본 상점을 닫거나 매입 탭으로 전환하면 함께 닫힙니다. 일시적으로 목록을 읽지 못하면 합계를 비우고 확인 대기를 표시합니다. 카테고리를 바꾸면 재화 창의 품목 종류 선택을 전체로 되돌립니다. 다른 NPC의 시트 목록으로 계산 범위를 자동 변경하지 않습니다.
- 보유 판단은 공개 수집 등록 API와 검사된 게임의 일반 등록 조회, 소지품·장비함·착용 장비·환상투영함/추억의 보관함입니다. 보관함 창이 닫혀 있어도 현재 캐릭터의 게임 아이템 찾기 캐시가 있으면 읽습니다. 환상투영 세트는 보유한 부위만 포함합니다. 기록된 집사·초코보 가방도 확인하며, 전체 보관함의 기록 완전성을 보장할 수 없으므로 양수 증거가 없는 품목은 미확인으로 남깁니다. 저장된 외형은 실제 교환 재화 보유량에 더하지 않습니다.
- Allagan Tools 공개 IPC로 현재 캐릭터 및 연결된 집사/공유 창고의 저장 기록을 조회합니다. 집사·초코보 가방·보관함의 양수 기록은 개인 보유 판정에 반영하며, 공유 물품은 개인 소유로 간주하지 않습니다. 현재 가방/재화의 저장 복사본은 실시간 수량에 중복 합산하지 않습니다. 환상투영함/추억의 보관함은 현재 게임 조회가 미확인일 때만 보유 보조 증거로 사용합니다. 연동 실패/캐릭터 전환 시 기록을 비웁니다. 다른 플레이어 캐릭터의 개인 가방은 조회하지 않습니다.
- 필요 재화 창 상단은 재화별 필요·사용 가능·개인 보관·총보유·추가 필요, 하단은 실제 합산한 품목/받는 수량/1회 비용/보유 판정입니다. 원본 상점의 현재 분류에서 각 교환을 한 번씩 계산하며 묶음 교환의 비용은 한 번만 더합니다.
- 재화 행에 마우스를 올리면 개인 보관, 부대 금고, 하우징 보관/배치, 장터 출품, 외형/착용 장비의 위치별 기록과 인출 필요량을 봅니다. 개인 보관에는 집사 가방/착용/길/크리스탈과 초코보 가방을 합산합니다. 나머지는 인출 권한·사용 조건 또는 중복 문제 때문에 참고 수량으로만 표시합니다. 집사 번호는 IPC 조회 순서이며 실제 집사 이름/정렬과 다를 수 있습니다.
- 총보유의 `≥`와 추가 필요의 `≤`는 **저장 기록 기준**의 하한/상한입니다. 미기록 보관함을0개로 보지 않으며, 기록이 오래됐거나 이동/소비가 반영되지 않았으면 실제 수량과 다를 수 있습니다. Allagan Tools에는 전체 적재 여부/보관함별 갱신 시각을 확인하는 해당 IPC가 없어 실시간 전체 재고라고 표시하지 않습니다. 연동이 없으면 기존 실시간 수량과 보관 미확인을 표시합니다.
- `수집 위주 보기`는 기존 소모품 체크 상태를 이어받습니다. 현행 교환식의 입력으로 확인된 잡화/기타를 강화·교환 재료로 분류하며, 이름의 접미사나 기타/잡화 전체를 기준으로 숨기지 않습니다. 분류가 불명확하면 유지합니다. 제외 규칙은 받는 품목에만 적용하며 지불 재화는 그대로 합산합니다. 일반 아이템 재화·HQ·석판·특수 화폐를 구분하고 복수 비용을 모두 더합니다. 다른 교환을 거슬러 올라가는 재료 소요량 계산은 아닙니다.
- 말풍선은 PvP(늑대우리 제외)에서만 검사한 네이티브 제한 처리를 조정하고, 해제/지역 이탈/언로드 시 원래 바이트를 복구합니다. 기본 말풍선이 꺼져 있거나 해당 채널이 꺼져 있으면 그대로 표시하지 않습니다. 전투/PvP 실기 확인은 남아 있습니다.
- 입찰 숫자는 공개 결과 로그로 수신한 것만 표시합니다. 본인의 선입찰·입찰·포기는 검증한 게임 상태로 먼저 표시할 수 있지만 숫자는 로그를 기다립니다. 다른 사람의 선택 완료 로그는 종류를 알려 주지 않으므로 결과가 없으면 포기로 추측하지 않습니다.
- 입찰 목록은 선입찰·입찰·미확인·포기/이탈 순이며 같은 종류에서는 높은 주사위부터 표시합니다. 상단에는 확인된 선입찰자/입찰자/포기·이탈자 수만 표시합니다. 포기와 이탈은 중복 집계하지 않고, 이탈한 사람은 앞의 선입찰/입찰 수에서 뺍니다. 미확인은 포기로 추정하지 않습니다. 실제 획득자는 별표와 금색으로 표시하며 순위 열/동점 안내는 없습니다.
- 관측 명단에서 두 번 연속 빠진 사람은 이탈로 표시하되 이전 선택/숫자를 보존합니다. 선택 미수신과 미선택 확정은 다르며, 접속 종료·퇴장 사유는 추측하지 않습니다. 재입장 관측 시 이탈 표시를 해제합니다.
- 같은 아이템 동시 드롭은 보상별 구분 불가로 안내합니다. 다른 연합원의 두 열은 실제 A/B/C 파티 구분이 아닙니다. 캐릭터/지역 전환과 해제 시 기록을 비웁니다.

## 빌드

Windows/.NET SDK10.0.402, Dalamud.NET.Sdk15.0.0/API15를 유지합니다. 네이티브 UI에는 MIT 라이선스 KamiToolKit의 고정 소스 revision을 사용합니다.

```powershell
git submodule update --init --recursive
./scripts/build.ps1
```

다른 참조 위치는 `-DalamudPath '참조 폴더'`로 지정합니다. 스크립트는 잠금 파일 복원·빌드·내장 자료와 원본 JSON/필수 의존성 검사를 수행하며 자동 테스트나 게임 조작은 하지 않습니다.

```powershell
. ./scripts/enter-dev.ps1
dotnet run --project tools/GameDataProbe -- resources src/DuckbillTweak.Plugin/bin/Debug/DuckbillTweak.dll
dotnet run --project tools/GameDataProbe -- native-contract '게임 경로/ffxiv_dx11.exe' "$env:DALAMUD_HOME/FFXIVClientStructs.dll"
dotnet run --project tools/GameDataProbe -- '게임 경로/sqpack' audit
```
