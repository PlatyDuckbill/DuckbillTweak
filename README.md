# DuckbillTweak

한국 FFXIV용 Dalamud 편의 기능 모음. 필요한 트윅만 켜서 사용합니다.

**0.1.2.0 개발본: 입찰 뷰에 선입찰·입찰·확인된 본인 포기, 선택 완료/미수신, 명단 이탈, 실제 획득자를 구분합니다. 선입찰 우선 순위와 상위3명 색상, 공동 순위를 추가했습니다. 8인 한 열/24인 세 열을 유지하며 늘어난 관측 명단은 스크롤합니다. 실전 화면 검증은 별도입니다.**

| 기능 | 사용 방식 |
|---|---|
| PvP 전장 말풍선 | 켜기/끄기만 제공. 채널·색·크기 등은 기본 대화 말풍선 설정을 따름 |
| 없는 품목만 보기 | 등록한 수집품·소지품·장비·로드된 환상투영함/추억의 보관함 제외. 종류/현재 카테고리별 선택 기억 |
| 소모품 제외 | 약품·요리·염료·촉매·효과 설명서·PvP 소모품·폭죽 제외, 등록 수집품 유지 |
| 필요 재화 | 상점 버튼으로 열기. 현재 상점 목록의 미보유 품목, 종류·거래 여부 필터와 전체 보기 |
| 아이템별 입찰 현황 | 원래 우클릭 메뉴 → 입찰 숫자 보기. 아이템 아이콘/이름, 참여자·선택 상태·숫자·순위. 8인 한 열/24인 세 열 |

설정과 결과 화면도 게임 UI 컴포넌트/글꼴/현재 테마를 사용합니다. 이전 ImGui 보조 목록, 자동 팝업, 별도 채팅 오버레이, 말풍선의 독자 설정, 입찰 기록 비우기 버튼은 제거했습니다.

## 개발본 사용

공개 설치 패키지/커스텀 저장소 배포는 아직 없습니다. 빌드 후 Dalamud 개발 플러그인에 아래 DLL을 등록합니다.

```text
src/DuckbillTweak.Plugin/bin/Debug/DuckbillTweak.dll
```

같은 폴더의 Core DLL, **KamiToolKit.dll**, Assets와 라이선스 파일도 유지하십시오. DLL 하나만 옮기지 않습니다.

1. `/dbtw` 또는 `/duckbilltweak`로 게임 스타일 설정을 열고 필요한 기능을 켭니다.
2. 상점을 닫았다 열면 원래 화면 안에 `없는 것만 보기`, `소모품 제외`, `필요 재화`가 표시됩니다.
3. 일반 길 상점에서는 종류를 선택한 뒤 제외 체크를 바꿀 수 있습니다. '모든 종류'에서도 개별 설정이 적용됩니다. 모든 종류에서 체크를 변경하면 개별 설정을 초기화합니다. 교환 상점에서는 카테고리/교환 목록별 체크를 기억합니다.
4. `없는 것만 보기`에 마우스를 올리면 보관함 정보와 Allagan Tools 연동 상태가 나옵니다. 게임 정보가 미확인이면 설치된 Allagan Tools의 현재 캐릭터 보관 기록도 확인합니다. 어느 쪽에도 정보가 없으면 환상투영함/추억의 보관함을 한 번 엽니다. 낡은 악보는 제작 결과 악보가 모두 등록됐으면 제외합니다.
5. 입찰 목록의 아이템 우클릭 메뉴에서 `입찰 숫자 보기`를 선택합니다. 미리보기 등 기존 메뉴는 유지합니다. `—`는 숫자 미수신이며 포기를 뜻하지 않습니다. 숫자는 입찰이 끝나 결과 로그를 받은 뒤 표시합니다.

이전 기능 켜짐 상태는 유지하고 설정 형식은 v2로 전환합니다. 신규 설치에서는 기능이 모두 꺼져 있습니다. `/dbtw shop`, `/dbtw loot` 보조 화면 진입은 제거했습니다.

## 지원 범위

- 검사한 한국 게임 실행 파일 SHA-256과 FFXIVClientStructs 모듈 ID가 일치할 때만 네이티브 기능을 활성화합니다. 현재 대상은 KR 2026.10.06.0000.0000 / 설치된 KR Dalamud15.0.3.9입니다.
- Shop, InclusionShop, ShopExchangeItem, ShopExchangeCurrency의 확인한 ULD 구조를 대상으로 합니다. 목록/원본 인덱스 연결을 확인할 수 없으면 원본 행을 유지합니다. 필터 적용 실패 시에는 체크 해제를 허용하고 사유를 툴팁/로그에 남깁니다. 모든 특수/군표/부대 상점을 지원하는 것은 아닙니다.
- 상점 필터는 원본 데이터 배열을 재정렬하지 않습니다. 표시 행 클릭 시 원본 인덱스·아이템·컨텍스트를 재확인하며 구매 확정은 게임 UI에서 직접 진행합니다.
- 상점이 열려 있으면 현재 카테고리의 실제 수신 품목/수량/비용을 계산합니다. 대체 경로의 기본 중복 선택을 방지하며 최저 비용 최적화는 아닙니다. 조건 또는 수량 미확인 교환식은 제외하고 그 수를 표시합니다. 다른 카테고리 전체를 자동 순회하지 않습니다.
- 재화 창은 원본 상점을 닫거나 매입 탭으로 전환하면 함께 닫힙니다. 일시적으로 목록을 읽지 못하면 합계를 비우고 확인 대기를 표시합니다. 카테고리를 바꾸면 재화 창의 품목 종류 선택을 전체로 되돌립니다. 다른 NPC의 시트 목록으로 계산 범위를 자동 변경하지 않습니다.
- 보유 판단은 공개 수집 등록 API와 검사된 게임의 일반 등록 조회, 소지품·장비함·착용 장비·환상투영함/추억의 보관함입니다. 보관함 창이 닫혀 있어도 현재 캐릭터의 게임 아이템 찾기 캐시가 있으면 읽습니다. 환상투영 세트는 보유한 부위만 포함합니다. 집사·초코보 가방은 제외하며 미확인 상태를 미보유로 추정하지 않습니다. 저장된 외형은 실제 교환 재화 보유량에 더하지 않습니다.
- 게임 보관함 정보가 미확인인 장비에는 Allagan Tools의 공개 `ItemCount` IPC를 선택적으로 사용합니다. 현재 캐릭터의 환상투영함/추억의 보관함에서 양수로 확인된 항목만 보유로 추가합니다. 0/오류는 미보유 증거가 아니며, 다른 캐릭터·집사 기록이나 재화 수량에는 사용하지 않습니다. Allagan Tools가 없으면 기존 게임 조회로 동작합니다.
- 필요 재화 창 상단은 재화별 필요·보유·부족, 하단은 실제 합산한 품목/받는 수량/1회 비용/보유 판정입니다. 원본 상점의 현재 분류에서 각 교환을 한 번씩 계산하며 묶음 교환의 비용은 한 번만 더합니다.
- 말풍선은 PvP(늑대우리 제외)에서만 검사한 네이티브 제한 처리를 조정하고, 해제/지역 이탈/언로드 시 원래 바이트를 복구합니다. 기본 말풍선이 꺼져 있거나 해당 채널이 꺼져 있으면 그대로 표시하지 않습니다. 전투/PvP 실기 확인은 남아 있습니다.
- 입찰 숫자는 공개 결과 로그로 수신한 것만 표시합니다. 본인의 선입찰·입찰·포기는 검증한 게임 상태로 먼저 표시할 수 있지만 숫자는 로그를 기다립니다. 다른 사람의 선택 완료 로그는 종류를 알려 주지 않으므로 결과가 없으면 포기로 추측하지 않습니다.
- 순위는 선입찰 우선, 같은 종류에서 높은 숫자 순입니다. 동점은 공동 순위이며 상위3명 색상과 실제 획득자의 별표를 함께 표시합니다. 미수신/종류 미확인은 순위에 넣지 않으며 최종 획득자는 획득 로그로만 확정합니다.
- 관측 명단에서 두 번 연속 빠진 사람은 이탈로 표시하되 이전 선택/숫자를 보존합니다. 선택 미수신과 미선택 확정은 다르며, 접속 종료·퇴장 사유는 추측하지 않습니다. 재입장 관측 시 이탈 표시를 해제합니다.
- 같은 아이템 동시 드롭은 보상별 구분 불가로 안내합니다. 다른 연합원의 두 열은 실제 A/B/C 파티 구분이 아닙니다. 캐릭터/지역 전환과 해제 시 기록을 비웁니다.

## 빌드

Windows/.NET SDK10.0.402, Dalamud.NET.Sdk15.0.0/API15를 유지합니다. 네이티브 UI에는 MIT 라이선스 KamiToolKit의 고정 소스 revision을 사용합니다.

```powershell
git submodule update --init --recursive
./scripts/build.ps1
```

다른 참조 위치는 `-DalamudPath '참조 폴더'`로 지정합니다. 스크립트는 잠금 파일 복원·빌드·내장 자료와 원본 JSON/필수 의존성 검사를 수행하며 자동 테스트나 게임 조작은 하지 않습니다.

```powershell
. ./scripts/enter-dev.ps1
dotnet run --project tools/GameDataProbe -- resources src/DuckbillTweak.Plugin/bin/Debug/DuckbillTweak.dll
dotnet run --project tools/GameDataProbe -- native-contract '게임 경로/ffxiv_dx11.exe' "$env:DALAMUD_HOME/FFXIVClientStructs.dll"
dotnet run --project tools/GameDataProbe -- '게임 경로/sqpack' audit
```
