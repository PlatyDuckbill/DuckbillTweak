# DuckbillTweak

한국 FFXIV용 Dalamud 편의 기능 모음. VanillaPlus와 SimpleTweaks처럼 필요한 기능을 각각 켜서 사용합니다.

**0.1.0 개발본입니다. 빌드와 오프라인 데이터 검사를 통과했으며, 인게임 동작은 확인 대기입니다.**

| 기능 | 현재 구현 |
|---|---|
| PvP 전장 채팅 말풍선 | PvP 지역(늑대우리 제외)에서 수신한 일반/파티/팀/연합 채팅을 주변 발언자 위에 표시. 채널·시간·너비 설정 |
| 상인 품목 필터 | 등록한 수집품 또는 현재 보유한 아이템 제외. 종류 선택, 종류별 제외 체크박스, 거래 여부, 검색, 전체 보기 |
| 필요 재화 | 필터에 맞는 교환식을 선택하고 재화별 필요·보유·부족량 계산. HQ/소장가치 구분, 중복 교환 경로의 기본 선택 방지 |
| 아이템별 입찰 숫자 | 전리품 추가/입찰/획득 로그를 모아 표시. 8인 이하 목록과 24인 연합 3열 화면 |

상인과 입찰 기능은 **별도 보조 화면**으로 구현되어 있습니다. 게임 상점/입찰 화면의 행이나 버튼을 수정하지 않습니다. 모든 기능은 기본 비활성입니다.

## 개발본 사용

현재 공개 설치 패키지/커스텀 저장소 배포는 없습니다. 아래 빌드 후 Dalamud 개발 플러그인에서 DLL을 등록합니다.

```text
src/DuckbillTweak.Plugin/bin/Debug/DuckbillTweak.dll
```

같은 폴더의 `DuckbillTweak.Core.dll`과 생성된 매니페스트도 필요합니다. DLL 하나만 다른 폴더로 옮기지 마십시오.

- `/dbtw` 또는 `/duckbilltweak`: 기능 설정
- `/dbtw shop`: 상인 보조 화면
- `/dbtw loot`: 입찰 보조 화면

상인 기능을 켜고 상인 NPC를 대상으로 선택하면 목록을 읽습니다. 상점 이용 시 보조 화면을 자동으로 여는 옵션도 있습니다. 직접 연결되지 않는 대화형 상점은 SpecialShop/GilShop ID로 열 수 있습니다.

계산 대상은 기본적으로 표시된 품목을 한 번씩 구매하는 교환식입니다. 판매 조건을 확인할 수 없는 교환식은 기본 선택에서 제외되며 직접 선택할 수 있습니다. 같은 품목의 다른 교환식을 선택하면 기존 경로가 해제됩니다. 이 선택은 최소 비용 최적화를 뜻하지 않습니다.

## 범위와 한계

- 길 상점, SpecialShop 교환 상점, TopicSelect/PreHandler/InclusionShop으로 연결되는 상점을 읽습니다. 별도 스크립트/군표/부대 상점 등 모든 NPC 상점 유형을 지원하는 것은 아닙니다.
- 보유 여부는 수집 등록 API와 일반 소지품·장비함·착용 장비를 기준으로 합니다. 집사·초코보 가방·보관함과 미수집한 외형 정보는 포함하지 않습니다.
- 길 가격은 시트의 기본 단가입니다. 할인·세금·퀘스트·축제·업적 등 실제 판매 조건은 게임 상점에서 확인해야 합니다. 소장가치별 소지량과 미확인 비용은 추정하지 않습니다.
- 특수 화폐 매핑은 KR `2026.10.06.0000.0000` 전용입니다. 다른 게임 빌드에서는 해당 매핑을 사용하지 않고 미확인으로 남깁니다.
- 말풍선은 플러그인 오버레이입니다. 원본 말풍선 제한을 메모리 패치로 해제하지 않습니다. 주변에 없거나 이름/월드를 연결할 수 없는 발언자는 표시하지 않습니다. 게임이 전송하지 않은 메시지를 복원하지 않습니다.
- 입찰은 실제 로그를 수신한 시점부터 표시합니다. 모든 플레이어의 숫자를 입찰 즉시 볼 수 있다는 보장은 없습니다. 미수신·선택 완료·실제 숫자를 구분합니다.
- 같은 아이템이 동시에 두 번 나오면 로그의 아이템 ID만으로 보상 슬롯을 연결할 수 없어 구분 불가로 표시합니다.
- 연합에서는 내 파티와 다른/미확인 소속의 관측자를 나눕니다. 다른 16명을 A/B/C 소속으로 추정하지 않으며, 실제 입찰 권한이 없는 플레이어를 참여자로 간주하지 않습니다.
- 기능 해제·캐릭터/지역 전환 시 관측 기록을 비우며 채팅/입찰 기록을 파일로 저장하지 않습니다.

## 빌드

DuckbillFisher와 같은 Windows/.NET SDK **10.0.402**, Dalamud SDK **15.0.0**·API **15**를 사용합니다. 이 PC에서 사용한 KR 참조는 **15.0.3.9**입니다.

```powershell
. ./scripts/enter-dev.ps1
dotnet restore DuckbillTweak.slnx --locked-mode
dotnet build DuckbillTweak.slnx -c Debug --no-restore
```

다른 위치의 KR 참조는 `. ./scripts/enter-dev.ps1 -DalamudPath '참조 폴더'`로 지정합니다. 게임이나 SDK 파일은 Git에 포함하지 않습니다.

오프라인 자료 검사는 설치된 게임의 sqpack 경로를 사용합니다.

```powershell
dotnet run --project tools/GameDataProbe -- '게임 경로/sqpack' audit
dotnet run --project tools/GameDataProbe -- '게임 경로/sqpack' logs
```
