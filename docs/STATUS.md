## 파티 전투 기록 분리

- 사용자 결정으로 미배포 파티 상태 타임라인·피해/회복·4분 목 데이터를 [DuckbillBattleTrace](https://github.com/PlatyDuckbill/DuckbillBattleTrace)로 옮겼다. 원본 관측 계약·출처·검증 이력도 새 저장소에 보존했다.
- DuckbillTweak의 Core/Plugin 코드·설정/명령/기능 상태·번역·진단 도구의 관련 추가분을 제거했다. 로컬 설계 예시도 새 프로젝트의 무시된 artifacts로 옮겼다. 기존 공개 기능·버전/Release·설치 목록은 변경하지 않았다.
- 정리 후 빌드·자료 검사 결과는 [확인 절차](VERIFICATION.md)를 따른다. 새 플러그인의 인게임 확인은 별개다.
- 새 프로젝트는 덕빌 Core/Plugin·고정 참조·한영 리소스·스모크/펄 테마 관례로 초기화했고, 공개 소스 저장소의 main에 초기 커밋1b4b520을 게시했다. 새 프로젝트 Debug·Release도 경고0/오류0·한영72키/위성·매니페스트/512px RGBA 아이콘 검사를 통과했다. 새 플러그인의 공개 Release와 공용 설치 목록 반영은 하지 않았다.

## 감정표현 상태 표시

- 감정표현 상태 표시(기본 꺼짐): 본인 기타 상태 정보/선택 대상 상태 영역에 네이티브 아이콘과 게임 툴팁의 이름·보유 중/미보유/보유 확인 불가를 표시한다. 일회성도 재생 중 표시하고 종료 시 숨기며 조회 실패/내부 동작은 확인 불가를 유지한다.
- 합친/분리한 HUD의 빈 칸 위치·배율을 사용하고 기존 상태는 변경하지 않는다. 칸 부족/개별 HUD 계약 실패는 그 표시만 숨기며 종료/전환/재생성 시 정리한다. [계약](NATIVE-UI.md#감정표현-상태-표시-개발본-2026-11-16)·[검사와 실기 순서](VERIFICATION.md#2026-11-16-감정표현-상태-표시-개발본).
- 사용자 화면에서 대상 아이콘 표시와 세로 늘어남·툴팁 미표시를 확인했다. 후속으로 정사각형 비율·실제 충돌 노드 툴팁·IsEmoting 기반 일회성 표시를 수정했다. 별도→정규 Debug·Release와 한영114키/위성·자료 검사는 완료했으며 최종 HUD/보유·호버/정렬/종료·재로드 확인은 대기다. 테스트는 추가/실행하지 않았다.
- 후속 아이콘 마감: 사용자 화면에서 사각 프레임/이름·보유 툴팁의 대표 표시를 확인했다. 이후 요청으로 원본 배경색을 유지하고 위쪽 뾰족한 은회색 프레임·호버 강조로 바꿨다. 별도→정규 Debug 경고0/오류0·한영114키/자료·색이 다른4종 오프라인 합성을 확인했다. 새 공개 API2개는 KR 두 참조에서 일치하며 게임 내 새 윤곽/배율·호버는 대기다.

## 기존 상태 안내

- 설정에서 각 기능의 상태 문구와 색 점을 함께 표시한다. 초록은 사용 준비/정상 대기/관찰/실행 중, 노랑은 접속·이동/관찰 표본 대기·지원 범위 밖·부분 지원, 빨강은 초기화·계약·관찰/적용 실패, 회색은 꺼짐이다.
- 음식 관찰과 준비 확인 표시의 중단을 구분하고, PvP 말풍선의 실제 적용 실패와 재화 교환 상점의 부분 지원을 안내한다. 계약 실패는 호버에서 기존 진단 코드를 확인한다.
- 기능 상태는 Framework에서 관리 값으로 복사해 표시한다. 설정 화면은 게임 객체를 읽지 않으며 상태 표본이2초 이상 갱신되지 않으면 확인 대기로 표시한다.
- 상태 안내만 추가했다. 측후/콤보 판정·네이티브 계약·게임 실행 동작과 기능 기본값은 유지한다. [구조](DEVELOPMENT.md#기능별-동작-상태-안내-2026-11-16)·[검증](VERIFICATION.md#2026-11-16-기능별-동작-상태-안내).
