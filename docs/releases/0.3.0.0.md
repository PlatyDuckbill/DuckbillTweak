# DuckbillTweak 0.3.0.0 — Redesigned feature settings

Manage features and their details together with the shared Duckbill design.

- Turn features on or off in grouped combat, shop and loot, and social settings.
- Adjust food thresholds, positional/combo markers and emote timing in each feature's detail panel.
- Read updates by their main feature and other improvements, with unread updates marked in settings.

- Preview each game icon in the choice list and configure positional outcomes in separate panels.

Other improvements:

- Adjust brightness, depth and transparency directly on the screen, with fine adjustments collapsed by default.
- Previously read updates stay read after temporarily using an older version.
- Collapse and close buttons no longer overlap when you click them.
