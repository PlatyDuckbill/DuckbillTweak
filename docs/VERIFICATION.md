## 인게임 대표 확인 대기

1. 같은 정규 개발 DLL을 리로드하고 `/dbtw`를 연다. 게임 테마의 설정 화면과 세 개의 기능 체크박스가 보여야 한다. PvP에는 세부 채널/너비/시간 설정이 없어야 한다.
2. 상인 기능을 켜고 스크린샷의 일반 길 상점을 닫았다 연다. 원래 화면 안에 없는 것만 보기/종류 선택/필요 재화가 표시되고 별도 보조 목록은 없어야 한다.
3. 실제로 소지한 장비와 등록한 수집품이 제외되는지, 종류 선택별 제외 체크가 기억되는지 확인한다. 보유 미확인 품목은 숨겨지면 안 된다.
4. 필터 목록에서 알려진 품목 한 개를 좌클릭해 구매 확인 화면의 아이템/가격이 같은지 확인한다. 실제 구매는 직접 판단한다. 필터 해제, 매입 목록 탭 전환, 상점 재열기, 플러그인 해제 후 원래 위치/클릭/스크롤이 복구돼야 한다.
5. InclusionShop 카테고리/하위 카테고리 전환과 ShopExchangeItem에서 원본 인덱스/아이템/비용 연결을 확인한다. 연결 미확인 시 체크가 비활성화되고 원래 목록을 유지해야 한다. 잘못된 아이템을 선택하는 상태는 허용하지 않는다.
6. 상점의 필요 재화 버튼으로만 계산 화면을 연다. 기본 미보유, 종류/거래 여부/전체 보기를 확인하고 길·시학·제작/채집 화폐·두 빛깔 보석의 이름/필요/보유/부족량을 대조한다. 조건 미확인 제외와 부분 합계는 안내가 있어야 한다.
7. PvP에서 기본 말풍선을 켠 상태/끈 상태, 기본 채널 설정 변경, 전투 중/대기 중을 확인한다. 플러그인은 on/off만 제공하고 기본 설정을 따라야 한다. PvP 이탈·플러그인 해제 후 원래 동작으로 돌아와야 한다.
8. 8인 입찰 목록의 실제 아이템 행을 우클릭한다. 미리보기 등 기본 메뉴와 '입찰 숫자 보기'가 함께 나와야 하고, 우클릭만으로 숫자 창이 열리면 안 된다. 추가 항목을 선택하면 아이템 이름이 위에, 이름/숫자가 한 열로 표시돼야 한다. 아이템을 바꾸면 제목/숫자도 바뀌어야 한다. 자동 팝업이나 비우기 버튼은 없어야 한다.
9. 24인은 세 열×8행을 확인한다. 실제 숫자를 받는 시점/입찰 권한의 범위를 기록한다. 미수신은 —이며 포기나0으로 추정하지 않는다. 같은 아이템 동시 드롭은 구분 불가 안내, 동명 다른 월드는 구분해야 한다.
10. 밝은/어두운 테마와 게임 UI 배율, 캐릭터/지역 전환, 플러그인 리로드/언로드에서 크기·글꼴·클릭 범위·중복 이벤트·잔여 노드를 확인한다.
